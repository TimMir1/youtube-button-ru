# MIRA & PAPA App

This application is built with React and Vite.

## Deployment to GitHub Pages

1.  **Export to GitHub** from Google AI Studio again to include the deployment workflow.
2.  Go to your repository on GitHub.
3.  Go to **Settings** -> **Pages**.
4.  Under **Build and deployment** -> **Source**, select **GitHub Actions**.
5.  Wait for the **Deploy to GitHub Pages** action to complete (check the **Actions** tab).
6.  Your app will be live at `https://timmir1.github.io/<your-repo-name>/`.
